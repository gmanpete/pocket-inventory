iPhone setup tips
  1. Host this HTML file at an HTTPS address (for example, GitHub Pages).
  2. Open that HTTPS address in Safari.
  3. Tap Share → Add to Home Screen. If shown, enable “Open as Web App,” then tap Add.
  4. Launch from the new Home Screen icon and allow camera access when prompted.
  5. Use Export JSON to back up your inventory.

Important: Camera scanning requires a secure HTTPS page and a compatible browser. This demo loads its QR/scanner libraries from the internet. The inventory itself is stored locally on this iPhone; it does not sync between devices.
